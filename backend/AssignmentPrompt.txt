React Assignment
Project Overview
For this assignment, you'll build a "Smart Task Manager." Think of it as a simple, mini
version of a productivity app, like a to-do list with a small dashboard. The main goal is to
create a working task manager that feels practical and useful, and you'll build it by using
different React hooks to manage its features and behavior.
Core Features (Must Have)
● Add Task: Users must be able to add a new task by providing a Title and
selecting a Priority level (High, Medium, or Low).
● Display Task List: All added tasks should be displayed in a list, with each item
clearly showing its Title, Priority, and current Status (Completed or Pending).
● Mark as Completed: Users can toggle the status of any task between
"Completed" and "Pending," typically with a checkbox or a similar control.
● Delete Task: Each task should have a method for permanent removal from the
list, such as a delete button.
● Search Tasks: Implement a search bar that allows users to filter the displayed
task list based on their input, matching against task titles.
● Filter Tasks: Provide filter controls that let users change the view to show All
tasks, only Completed tasks, or only Pending tasks.
● Theme Toggle (Light/Dark): Include a switch that toggles the entire user
interface between a light theme and a dark theme, demonstrating dynamic
styling
