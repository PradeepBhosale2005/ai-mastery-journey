Assignment : Smart Expense Processing
Workflow
Objective
Build a LangGraph workflow that processes a user's expense and decides how it should be
handled based on the amount.
The workflow should simulate a company expense approval system.
Problem Statement
Create a graph where a user submits an expense amount in USD.
The system should:
1. Add 10% tax to the expense.
2. Convert the final amount to INR.
3. Route the request based on the expense amount:
○ If amount ≤ 100 USD → Auto Approved
○ If 100 < amount ≤ 1000 USD → Manager Approval
○ If amount > 1000 USD → Finance Department Approval
Finally, the workflow should print the final decision and converted amount
