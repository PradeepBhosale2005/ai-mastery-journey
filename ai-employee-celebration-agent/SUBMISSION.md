# LMS Submission Details

## AI Agent Use Case Name Selected from LMS

AI Employee Birthday & Work Anniversary Celebration Agent

## Selected LMS Use Case Description

AI agent integrates with Workday APIs to identify birthdays and anniversaries, checks employee status and timezone, generates personalized Gen-AI messages, and automatically sends emails or celebratory posts on Jadean Jar.

## Implementation Summary

This project implements a working MVP using mock Workday employee data. It scans active employees, checks birthdays and work anniversaries for the selected business date, generates personalized messages, and records simulated Email or Jadean Jar notifications.

## Current MVP Scope

- Mock Workday employee data
- Active employee validation
- Timezone-aware local date support
- Birthday detection
- Work anniversary detection
- Mock or OpenAI-compatible LLM message generation
- Email/Jadean Jar notification simulation
- JSONL audit logging
- Streamlit demo UI
- Unit tests
