# Final Project Submission - AI Employee Birthday & Work Anniversary Celebration Agent

## Project Name

AI Employee Birthday & Work Anniversary Celebration Agent

## HR-Friendly Product Name

Employee Moments Assistant

## Selected LMS Use Case

AI agent integrates with Workday APIs to identify birthdays and anniversaries, checks employee status and timezone, generates personalized Gen-AI messages, and automatically sends emails or celebratory posts on Jadean Jar.

## Final Submission Summary

This project implements an HR-friendly AI assistant that reads employee celebration data from a Workday RaaS report, identifies birthdays and work anniversaries, previews AI-generated celebration messages, and prepares safe delivery records. The SMTP and generic API delivery framework is included, but real sending should remain disabled for the final demo unless approved.

## Key Features Completed

- Workday RaaS JSON integration for `RPT_AI_Employee_Celebration_Agent`
- Exact mapping for the available Workday fields
- Birthday detection using `Date_of_Workers_Next_Birthday`
- Work anniversary detection using `Original_Hire_Date`
- Active employee validation
- Upcoming celebration view
- HR-friendly Streamlit UI: `app_hr.py`
- AI message preview using mock mode or company LLM configuration
- Dry-run delivery safety
- Local JSONL outbox for auditability
- SMTP delivery framework for later enablement
- Generic API posting framework for later enablement
- Tests for report mapping, upcoming celebrations, and delivery framework
